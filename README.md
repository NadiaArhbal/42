\## 🛠️ Technical Constraints Enforced

Across all implementations, strict system guidelines were enforced to build defensive programming habits:

1\. \*\*The "Norme" Compliance:\*\* Absolute architectural layout limits (maximum 25 lines per function, 5 variables per scope, no loop nesting abuse).

2\. \*\*Strict Warning Compilations:\*\* Mandatory build flags matching `-Wall -Wextra -Werror` to block runtime anomalies before testing execution.

3\. \*\*Manual Memory Sanitization:\*\* Complete manual allocation tracking (`malloc`, `free`), ensuring zero memory leaks or segmentation faults.
